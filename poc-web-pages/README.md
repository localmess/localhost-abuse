# Reproduction of results

## Methods used by Meta and Yandex
The folder called `poc-web-pages` contains various .html and .py files allowing for the reproduction of the methods used by Meta and Yandex
`localhost_channel_methods_page.html` contains recreations of the five methods these companies used.
 - **HTTP**: method using requests send to the localhost over HTTP. Used by Yandex since February 2017 until June 2025 and by Meta since September 2024 until October 2024. Run `test_server.py` to receive these requests. Note that the Brave browser will block these requests by default.
 - **HTTPS**: method using requests send over HTTPS to a domain resolving to 127.0.0.1. Used by Yandex since May 2018 until June 2025. Run `test_server.py` to receive these requests. To run this method, make sure you use a domain that resolves to 127.0.0.1 (e.g. by rebinding it in your device's host file). The receiving server alos needs a cerificate for that domain. A certificate can be created in the same folder as the scripts using the following command: `openssl req -x509 -newkey rsa:2048 -nodes -keyout key.pem -out cert.pem \ -days 365 \ -subj "/CN=myapp.local" \ -addext "subjectAltName=DNS:myapp.local"` After the creation of the certificate, run `test_server.py` and visit the domain at the port it is hosted in a browser (default is `https://myapp.local:5001`). When prompted, accept the certificate. Once these steps are finished, the server should be able to receive the requests send using this method. Note that the Brave browser will block these requests by default if sent to 127.0.0.1 directly and not to a domain resolving to this address.
 - **WebSocket**: method establishing a WebSocket connection with a server at the localhost. Used by Meta from November 2024 to January 2025. Run `test_server.py` to receive these requests. Note that the Brave browser will block these requests by default.
 - **WebRTC STUN**: method using WebRTC STUN binding requests. The _Send with STUN_ button uses the method as used by Meta with the correct SDP-munging technique, while _Send with Adapted STUN_ uses a different version of SDP-munging in case the first method is blocked by the browser. Used by Meta from November 2024 to June 3rd. Run `webRTC.py` to receive the binding requests. Note that the Firefox browsers blocks these requests by defautl.
 - **WebRTC TURN**: method using WebRTC TURN requests that does not rely on SDP-munging. Implemented by Meta from May 2025 to June 3rd. Run `webRTC_turn.py` to receive the binding requests. The server currently needs to be restarted after each received request.
